## Troubleshooting Common Issues

Install issues? Discard the first run after a driver install, since shader compilation distorts results.  
Performance problems? Repeat the same route for every comparison.  
License/activation? Check that frame limits are identical between runs.  
Compatibility? Verify the overlay is permitted by the game.  
Update failures? Export data before a reinstall to keep your history.
